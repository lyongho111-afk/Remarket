# 캠퍼스 리마켓 수정 완료 계획서
작성일: 2026-10-29 / 버전: 학생용 가게 화면 수정본 v9

## 목적
기존 카드형 메인과 서비스 흐름을 유지하면서 start07 예제처럼 DTO → DAO → XML Mapper → Service → Controller → HTML로 소스를 구성한다. 기존의 별도 표 화면을 메인으로 보여주던 문제를 수정하고, 카드 화면의 버튼이 서버 기능에 직접 연결되도록 한다.

## 메뉴와 화면
중고거래 / 동네생활 / 가게 / 내 판매글을 제공한다. 모임 탭은 제거한다. 학교는 인하대학교로 표시한다. 내 판매글 옆 숫자는 실제 예시 계정 판매글 수를 따른다. 내 판매글은 별도 관리 페이지로 전환한다. 지도·결제는 상품 상세 안에서 들어가며 상단 독립 결제 탭은 두지 않는다.

## 할인
판매자는 금액을 직접 계산하지 않고 할인율을 입력한다. 10·20·30% 빠른 선택을 제공하고, 기존 판매가·할인가·절약액·종료 예정 시각을 보여준다. 예: 28,000원 × 20% 할인 = 22,400원, 5,600원 절약. 정수 1~99%, 할인 후 최소 1원, 원 미만 버림이다. 할인은 시작 후 정확히 24시간 적용하고 만료되면 원래 가격을 보여준다. 할인 중 시간 연장·원가 변경은 제한하고 조기 종료를 허용한다. 예약 확정 가격은 별도로 보관해 할인 종료 후에도 유지한다.

## 노출과 끌어올리기
최신 → 끌어올리기 → 판매 중(온도 높은 순) → 예약 중 → 거래 완료. 최신·끌어올림 우선 노출을 각각 24시간으로 두며, 끌어올리기는 게시글당 24시간 간격이다. 최신 글을 끌어올려도 최신 구간을 먼저 적용한다. SQL과 화면에서 같은 우선순위로 계산한다. 가격순을 선택하면 사용자가 고른 가격 기준으로 정렬한다.

## 실제 연결 범위
판매글 등록·수정·삭제, 할인 시작·종료, 끌어올리기, 게시판 등록·수정·삭제, 가게 조회, 예약 생성·취소, 약속 장소 저장, 대면 거래 완료를 MyBatis XML SQL에 연결한다. 금액은 서버가 계산하고 예약 시 DB 조회 금액을 보관한다. 버튼 처리 실패는 화면에서 오류로 안내한다. 찜은 브라우저 세션에서 유지한다.

## 지도·결제
Google 지도 임베드·위치 링크를 제공하고 Maps JavaScript API 키 설정 시 지도 클릭 좌표를 약속에 저장할 수 있게 한다. 공개 데모 키의 인증·사용 제한은 Google 정책을 따른다.
토스 카드 테스트 SDK 진입, 서버 주문 준비·금액 검증·승인 결과 기록 코드를 포함한다. 발급한 테스트 클라이언트·시크릿 키가 없어 승인 성공은 미검증이다. 키 미설정은 화면에서 명시하고 결제를 막는다. 대면 거래 완료를 토스 승인이나 송금으로 표현하지 않는다. 실결제·환불·정산·가상계좌 입금 웹훅은 별도 구현 사항이다.

## 데이터와 실행
실행용 H2 schema.sql/data.sql과 XML Mapper를 포함한다. 서버 실행 중 데이터는 DB에 보관되며 브라우저 새로고침에는 유지된다. 메모리 H2이므로 서버를 종료하면 초기화된다. 사용자 요청에 따라 영구 저장 기능을 추가하지 않는다.
Windows 64비트 실행용 Java 런타임과 JAR, 전체 IntelliJ Gradle 소스, SQL, 이 계획서와 작성 순서 안내를 ZIP에 함께 제공한다. 소스 수정·빌드는 JDK 25와 Gradle 동기화가 필요하다. 외부 공유주소는 실행 PC·임시 터널이 켜져 있는 동안 유효하다.

## 검증과 남은 범위
카드 화면에서 등록·수정·할인율 자동 환산·끌어올리기·예약 가격·거래 장소 변경·거래 완료·동네생활 글쓰기를 직접 검증했다. Service 테스트와 HTTP API 검증 결과는 docs에 포함한다. 실제 사용자 인증·권한·채팅·댓글 및 발급 키를 사용한 토스 승인 성공 검증은 포함하지 않는다.


## 학생용 가게 화면 수정 (v9)
배너 아래 중고거래·동네생활 바로가기 바를 제거한다. 상단 주요 메뉴는 유지한다.
가게 탭은 왼쪽에 인하대학교 주변 Google 지도, 오른쪽에 ‘공강에 들르기 좋은 곳’ 목록을 나란히 배치한다. 좁은 화면에서는 위아래로 배치한다. 지도에는 캠퍼스 주변·카페·식당 보기와 큰 지도 링크를 제공한다. 가게 목록에서는 가게명·영업 상태·영업시간·메뉴·여유 공간을 확인하며 가게를 누르면 공개 이용 정보만 보여준다.
학생 입장의 홈페이지이므로 카페 상태 변경 시연, 유효 시간, 반영 버튼, 가게 편집·삭제 화면은 제공하지 않는다. 학생용 가게 Controller는 GET 조회만 제공한다. 사장·관리자 화면은 학생 페이지 완성 후 별도 작업으로 남긴다.
나머지 중고거래·동네생활·내 판매글·할인·끌어올리기·거래 지도·결제 흐름과 SQL 테이블은 그대로 유지한다. 기존 start07 방식 DTO → DAO → XML(SQL) → Service → Controller → HTML 구조를 유지한다.
