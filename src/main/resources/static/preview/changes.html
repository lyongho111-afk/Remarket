이번에 달라진 캠퍼스 리마켓

학교생활과 커뮤니티

동네생활을 학교생활로 바꾸고 앱에 등록된 업체를 지도에 표시했습니다. 영업중은 초록, 혼잡은 주황, 영업종료는 회색, 휴무는 빨강입니다. 공개 승인과 위치 등록이 완료된 업체만 지도에 표시됩니다.

별도 커뮤니티에서 맛집·술집 추천, 가성비, 공지, 자유게시판 글을 나눌 수 있습니다. 기존 분류와 글도 유지합니다.

센터 이동과 광고 배너

로그인한 사장과 매니저에게 각 센터로 이동하는 링크를 추가했습니다. 메인 배너 3장은 자동으로 바뀌며 이전·다음·직접 선택·일시 정지를 지원합니다.

판매자 거래 약속 알림

구매자의 예약 확정 시 판매자 알림이 생성됩니다. 상단 알림에서 약속과 외부 알림 상태를 확인하고 수신 연락처·채널을 설정할 수 있습니다.

문자·이메일·카카오 실제 발송에는 운영자의 외부 서비스 설정이 필요합니다. 설정 전에는 발송 완료로 표시하지 않습니다. 자세한 설정은 프로젝트의 v14_변경사항.md를 확인하세요.

DB 정리

사용하지 않는 사장·매니저 인증용 중복 컬럼과 reputation 등 Shop 필드 12개를 제거했습니다. 실제 로그인 정보는 기존 회원 테이블에서 관리합니다. 가게 주소·위도·경도를 추가했습니다.
